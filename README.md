# Cotizador Parrillas Green

Herramienta web para calcular rápido el total de un pedido de Parrillas Green
mientras se conversa con el cliente por WhatsApp.

## Qué hace
- Permite elegir uno o varios productos y su cantidad.
- Permite elegir recojo en punto de venta (sin costo) o delivery en Lima (+ S/ 5.00).
- Calcula el total y genera un resumen listo para copiar y pegar en WhatsApp.

## Cómo usarlo
Abre el enlace de la página desde el celular y arma el pedido.
También puedes abrir el archivo index.html directamente en el navegador.

## Cómo cambiar los precios
Los precios están al inicio del código de index.html, en la lista PRODUCTOS.
Edita el número junto al nombre del producto y guarda el cambio.

## Qué NO incluye (por ahora)
Pagos en línea, registro de clientes, historial de pedidos ni inicio de sesión.

## Tecnología
Una sola página HTML con CSS y JavaScript. No usa base de datos ni servidor.
